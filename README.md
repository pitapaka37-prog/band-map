# バンド相関図

バンド名を入れると、メンバー・元メンバー・つながり・同じジャンルのバンドがわかる無料の検索アプリです。

- 定番・インディーのバンド186組を収録（オフラインでも表示）
- 収録外のバンドは [MusicBrainz](https://musicbrainz.org/) と Wikipedia からその場で取得（APIキー不要）
- ジャンル・年代・地域から探す
- 自分でバンドを登録（ブラウザに保存）
- ホーム画面に追加できるウェブアプリ（PWA）

GitHub Pages で公開しています。データの出典: MusicBrainz（CC0）、Wikipedia（CC BY-SA）。
